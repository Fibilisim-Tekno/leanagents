# Changelog

## 0.1.0-alpha.1 — 2026-09-14

Initial public alpha.

- Explicit task routing and selected instruction packets.
- TypeScript snapshot review with source and usage records.
- Bounded fix, immutable test checks, separate review and guarded application.
- Instruction exports for Codex, Kiro, Cursor and Antigravity.
- Offline catalog validation, token budgets and fixture scoring.
- Local tests and a Windows/Linux CI configuration.

Native runtime validation is limited to the documented Codex checks. Additional
specialists, general repository editing and comparative quality evaluations
remain future work. This release makes no general token-savings claim.
